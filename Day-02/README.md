# Day 02 – Retail Sales Calculator

## Project Overview

A Python-based Retail Sales Calculator that calculates key business metrics using product information provided by the user.

This project is part of my 100 Days of Python learning journey and supports my career goal of becoming a Data Analyst and Data Scientist.

## Learning Objectives

- Python primitive data types
- Type checking and type conversion
- Mathematical operations
- Variables and user input
- F-strings and string formatting
- Formatting numbers to two decimal places

## Project Features

The program accepts the product name, selling price, cost price and number of units sold.

It then calculates and displays:

- Total revenue
- Total cost
- Total profit
- Profit margin percentage

## Example Output

```text
WELCOME TO THE RETAIL SALES CALCULATOR

Product: Laptop
Selling price: 8500
Cost price: 6000
Unit sold: 12

----SALES REPORT----

Product: Laptop
Unit Sold: 12
Total revenue: R102000.00
Total cost: R72000.00
Total profit: R30000.00
Profit margin: 29.41%
```

## Challenges and Lessons Learned

During this project, I encountered type errors when performing mathematical operations on user input. I learned that Python's input() function returns strings by default and that numerical inputs must be converted using float() or int().

I also improved my understanding of f-strings and formatting financial results.

## Relevance to Data Analytics

Revenue, cost, profit and profit margin are important business performance metrics. This project helped me understand how Python can be used to automate basic financial calculations and generate business reports.
