# Day 01 - Career Profile Generator

## Project Description
A beginner-friendly Python program that collects user information and generates a personalised career profile.

## Concepts Practised
- Python variables
- Variable naming
- User input using input()
- Output using print()
- String concatenation
- New lines and output formatting

## How to Run
Run the following command from the Day-01 folder:

`python Career_Profile_Generator.py`

## What I Learned
I learned how to collect user input, store information in variables and combine strings to generate personalised output.

## Self-Reflection
This project helped me apply Python fundamentals independently and improve my programming confidence.
